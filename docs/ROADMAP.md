# Roadmap

## Phase 01 — Foundation

Versioned JSON metadata, lifecycle gates, provenance/unknown handling, governance,
deterministic validation, and least-privilege GitHub review workflows. No market
or scientific result is claimed by this phase.

## Phase 02A — Discovery metadata

Bounded public metadata discovery, an evidence-preserving candidate registry,
an offline release gate, and a provisional source-review shortlist. See
`DISCOVERY_PROTOCOL.md` and `CANDIDATE_MATRIX.md`. No source-reviewed or validated
market finding is claimed.

## Phase 02B — Proposed only; not authorized or implemented

1. Select a pilot via human review; inspect source at a pinned SHA and license.
   Document competing mechanisms, assumptions, asset-transfer limits, and tests.
2. Propose a separately approved reproduction plan with commands, dependencies,
   resource limits, public/synthetic data, rights, expected artifacts, and falsifiers.

Acceptance: one reviewable mechanism/reproduction proposal, not a profitable
strategy or validated market claim. Do not implement automated acquisition or
execution, RAG, or market feeds under Phase 02A.
